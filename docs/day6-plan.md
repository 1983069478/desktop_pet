# Day 6 计划：UI/UX 细节优化

**日期**：2026-08-05

**目标**：打磨交互细节，让宠物更生动、更好看，接近最终可演示的成品。

---

## 任务清单

### ① 进化特效动画

进化是最重要的时刻，需要视觉冲击力：

| 效果 | 说明 |
|------|------|
| 进化光柱 | 宠物被一道金色光柱包裹，持续 1.5 秒 |
| 粒子散开 | 光点从宠物中心向外飘散 |
| 阶段切换 | 光效结束后自动切换新形态 |

用纯 CSS 动画 + Canvas 粒子实现，不需要额外资源文件。

### ② 打卡成功反馈

目前打卡完弹窗直接关闭，体验太平淡：

| 效果 | 说明 |
|------|------|
| 经验飘字 | 打卡后 "+10 专注" 从宠物上方飘起消失 |
| 宠物抖动 | 打卡瞬间宠物轻微左右摇晃（开心反应） |

### ③ 窗口位置记忆

目前关闭应用重开后，窗口总是回到右下角默认位置：

- 退出时保存窗口坐标到 localStorage
- 启动时恢复到上次位置
- 首次使用仍使用默认位置（右下角）

### ④ 拖拽体验优化

| 改进 | 说明 |
|------|------|
| 拖拽时取消动画 | 拖拽中暂停浮动动画，松手后恢复 |
| 吸附边缘 | 拖到屏幕边缘时自动吸附（可选） |

### ⑤ 整体复查

- 三天交互（单击/双击/右键）确认无冲突
- 打卡 → 进化 → 链上交易 全链路走通
- 重置后所有状态归零
