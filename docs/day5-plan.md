# Day 5 计划：NFT 状态面板与全链路完善

**日期**：2026-08-05

**目标**：制作 NFT 主面板，展示链上信息，完善"打卡→进化→链上更新"完整体验。

---

## 背景知识

- 目前宠物已经能打卡、累积经验、触发进化交易
- 但用户还看不到链上的 NFT 信息（Token ID、合约地址、浏览器链接）
- Day 5 要做一个主面板，双击宠物就能打开，像"宠物身份证"一样展示所有信息

---

## 任务清单

### ① NFT 状态主面板

新建 `NftPanel.vue`，双击宠物打开：

| 展示内容 | 说明 |
|----------|------|
| 宠物形象预览 | 当前阶段的宠物动画 |
| NFT Token ID | 链上的唯一编号（如 #0） |
| 合约地址 | 可点击跳转 Monad 浏览器 |
| 四维属性柱状图 | 专注 / 智慧 / 创造 / 共情 的数值对比 |
| 当前阶段 | 宠物蛋 / 幼体 / 进化体 |
| 总经验值 | 累计经验数值 |
| 最近交易链接 | 上一次进化/铸造的 Monad 浏览器链接 |

### ② 属性柱状图

用纯 CSS 实现简单的横向柱状图，展示四项属性数值：

```
🎯 专注  ████████████ 30
🧠 智慧  ██████ 20
🎨 创造  ████████ 25
💛 共情  ██████ 20
```

### ③ 双击打开面板

- 在 `PetWidget.vue` 中区分双击和单击
- 单击 → 弹跳反馈（目前已有）
- 双击 → 打开 NFT 主面板
- 双击检测：300ms 内连续点击 2 次

### ④ 总经验归零后重新进化（完善体验）

- 进化成功后经验归零（Day 4 已实现）
- 从阶段 0 到阶段 1 需要 30 经验（3 次打卡）
- 阶段 1 到阶段 2 也需要 30 经验
- 让进化链路可以完整走完：蛋→幼体→进化体

### ⑤ 修复点击行为

- 单击宠物：弹跳反馈（已由用户修改）
- 双击宠物：打开 NFT 面板
- 右键宠物：弹出菜单
