### ④ 录制 Demo 视频

用录屏工具录制 1-2 分钟演示：

**推荐录屏工具**：
- Windows 自带：`Win + G` 打开 Game Bar → 录制
- 或 OBS Studio（免费）

**演示脚本**：

```
1. 开场（10 秒）：桌面全景 → 宠物在右下角浮动
2. 拖拽（10 秒）：把宠物拖到屏幕中间
3. 打卡（30 秒）：
   - 右键 → 快捷打卡
   - 选"专注" → 确认 → "+10 专注"飘字 + 抖动
   - 重复 2 次，进度条涨到 30/30
4. 进化（25 秒）：
   - "✨ 可以进化了！"按钮出现
   - 点击 → 光效包裹 → 成功爆发 → 新形态
5. NFT 面板（10 秒）：
   - 双击宠物 → 面板打开
   - 展示 Token ID、属性柱状图
   - 点击浏览器链接跳转
6. 结束（5 秒）：宠物在桌面悠闲浮动
```
